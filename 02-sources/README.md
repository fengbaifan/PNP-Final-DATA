## 原则

1. 来源文件只读：摄入、验证、enrich 均不得改写来源本体。
2. 摄入必须保留覆盖证明；禁止用脚本替代语义阅读。
3. 新来源登记走摄入工作包（`03-processing/`），不在这里写处理状态。
