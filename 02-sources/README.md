# 02-sources — 原始来源层

科研级主干的原始来源层。**来源本体只追加，不改写、不删除**；顶层登记类文件（本 README、`source-registry.md`）可更新但不得删除。

## 目录

| 子目录 | 内容 |
|---|---|
| `01-book/` | 《赞助人与画家》23 个章节 PDF（封面 + 正文 17 章 + 书后材料 5） |
| `02-Markdown/` | 英文 OCR、整章校勘副本及派生视觉转录；资产与 S0 规范来源的区别见来源登记 |
| `03-Index/` | 原书人名/机构/地名索引三格式（MD/CSV/PDF） |

来源登记（doc-id、书前材料、全书结构）见 [`source-registry.md`](source-registry.md)。

## 原则

1. 来源文件只读：摄入、验证、enrich 均不得改写来源本体。
2. 摄入必须保留覆盖证明；禁止用脚本替代语义阅读。
3. 新来源登记走摄入工作包（`03-processing/`），不在这里写处理状态。
4. S0 来源摄入、S1 候选与 S2 语义处理的过程及结果分别写入同包 `process/stages.md`、`results/stages.md`；来源登记仍在本目录更新。已有 `patrons-and-painters/` 来源包和资产按来源保留规则维护，不搬动来源文件。
