## 内容

### 描述

**中文：** 本卡登记Haskell第9章注4所列Musée Jacquemart-André机构。中文显示名采用音译，不是馆方中文名。馆方网站使用同一机构名称并发布与本批壁画相符的作品记录。本机构端点与博物馆所在的实体建筑保持类型区分。

**English:** This card registers the Musée Jacquemart-André institution named in Haskell’s Chapter 9, note 4. The Chinese display name is a transliteration, not an official museum rendering. The museum website uses this institutional name and publishes the matching fresco record. The institution is kept distinct from the physical building that houses it.
