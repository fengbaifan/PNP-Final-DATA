## 内容

### 描述

**中文：** 本卡登记第六章第155页注3所指的1783年罗马科隆纳收藏目录。哈斯克尔明确称目录匿名出版。WorldCat记录提供意大利文题名、出版者及OCLC号，并把Palazzo Colonna列为编目责任者入口；该目录的题名页未在本批查阅，因此不以数据库责任者索引推翻书内的匿名表述。目录正文未独立阅读。

**English:** This card records the 1783 Rome catalogue cited in chapter 6, page 155, note 3, in connection with the Colonna collection. Haskell explicitly describes the catalogue as anonymously published. WorldCat supplies an Italian title, publisher, and OCLC number, and indexes Palazzo Colonna as a cataloged-author access point; the title page was not inspected for this batch, so that access point does not override the book’s anonymous description. The catalogue text was not independently read.
