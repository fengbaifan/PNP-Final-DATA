阶段 3–6 负责知识元、对齐、补足与关系；第二部分启动后由这些材料逐级涌现结构。
分析与决定保存在 03-processing/<task-id>/process/knowledge.md；本目录 results/<task-id>.md 保存当前结果、成果引用、状态和缺口。读取先定位当前结果，再按问题回查相应过程与证据，不在本目录重建 process。
units 是 KU 唯一正文，quality 保存断言、证据和关系，structure 保存实际形成的层级。
accepted.yml 只登记本项目有效 KU 路径、claim_id 和结构路径，不复制内容；实际成稿或结构成立后才加入，没有依据不登记。
现存试填资料保持可追溯，未经本项目接收不计为成果。层级与验证字段仅在对应工作实际开展后记录，既有字段不证明本项目完成。
