# 知识、证据与当前结果

`tables/` 保存 S0–S6 结构化产物，是提及、断言、对齐、字段表行和正式关系的工作事实源；`ku-manifest.csv` 负责 KU 登记及计数。`units/` 保留唯一 KU 正文、元数据、散文与由表渲染的视图，卡片字段表和关系表不另行维护第二份事实。`quality/` 中的既有断言证据、验证日志、候选和派生索引各有职责，不将整个目录统称为关系权威。`structure/` 只保存实际形成的发现结构。

`accepted.yml` 登记本项目有效对象、claim 与结构范围，不复制内容，也不表示全部身份、事实及关系已经验收；未接收的旧文件不计为成果。

当前进度以[全书 S2 结果](results/patrons-and-painters-full-book-s2.md)为准。第一章、章前材料和第六章既有记录按各自范围保留；全书 S2 复用、核对及迁移的状态由全书结果说明，不能从旧报告或表文件存在推导本轮 S3–S6 已完成。知识发现与页面暂停。

过程在 `03-processing/<task-id>/process/`，本目录 `results/<task-id>.md` 只保存当前状态、成果入口和未决项。先读当前结果，再按问题回查过程与来源，不在本目录重建 process 或复制历史游标。
