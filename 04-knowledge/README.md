# 知识元、知识图谱与后续发现

本目录承接 03-processing 的结果，负责阶段 3 知识元、4 对齐、5 补足、6 关系；每个对象分别记录实际进度。完整流程见 `.agents/pipeline.md`。

- process/<id>.md：按阶段记录语义判断、来源证据、修改理由与未决问题。
- results/<id>.md：对应对象的当前成果链接、各阶段完成状态、证据边界和缺口。
- units/：8 类知识元的唯一当前正文。
- quality/：断言、证据、验证记录及正式关系索引；不是第二份知识元正文。
- structure/：后续发现与涌现的正式结构；初期 Theme/Topic 挂载暂不开展。

同一 id 对应同一对象/工作包，固定文件持续更新，不按轮次复制。结果文件引用实际成果，不复制正文。已有知识不因规则重构获得新的语义验收状态。
