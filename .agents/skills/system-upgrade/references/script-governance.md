# 辅助脚本边界

直接语义工作优先，不为了执行短任务新增脚本、依赖或通用框架。
脚本适合可机械判定的定位、格式/引用检查、索引、批量受控写回和页面实现；不能裁决对象同一性、事实、关系语义或研究结构。

已有代码修改前读直接调用者和数据格式。保留真实证据、失败状态和恢复边界；同一文件串行。批量写回需要预检和可恢复提交，普通单对象语义编辑无需复制一套机器事务文档。
frontmatter 解析应处理 UTF-8/BOM 与整行分隔符。统计完整输入集合后再截断预览；内容/事实质量不能用长度或标点评分。
新项目展示输入由 accepted.yml 指定，生成器不能因为旧文件还存在就展示旧结果。来源/内容变化要追踪相关下游，不强制每一步刷新全库。
改代码运行必要回归，改文档核对相关契约与引用。删除工具前核实调用者、测试和直接 reference；没有实际理由不清理可用辅助工具或强制每轮生成 provenance。
