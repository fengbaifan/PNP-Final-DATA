# 系统调整的必要检查

按变化选择检查，不设置固定审批链或评分门槛。

- 文本/导航修订：检查目标规则和直接引用是否一致，记录实际变更与限制。
- Skill 变化：校验唯一名称、触发词、路径和直接 reference，派生注册表按需刷新。
- 脚本/格式变化：运行能检验受影响行为的回归；必要时扩大，已通过且无新问题不重复全套。
- 批量写回接口变化：保留预检、差异审阅、失败不冒充成功和恢复时核对输入的能力。
- 页面数据变化：核对有效输入、真实统计、空状态、链接与交互，保留现有视觉样式。
- 生成文件变化：核对受影响输出；需要幂等时比较重复生成哈希。仅在明确提交/发布任务中对提交基线核验，不要求未提交修改与 HEAD 一致。

检查由 Agent 在任务内完成，不自动要求用户批准。发现回归修复后复核相关部分；不能以新增待办掩盖任务内应解决的问题。历史成果或来源不得为通过新检查而伪回填。
