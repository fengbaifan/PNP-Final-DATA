# 对象类型、命名与消歧

基础 KU 类型见 01-domain/taxonomy-registry.md。类型是表达方式，不预设研究结论；Topic、Theme、Dimension、Domain 是后续涌现结构，claim 是断言层，Cluster 是观察线索。

文件使用稳定英文 kebab-case slug，类型目录对应 person/persons、family/families、institution/institutions、place/places、work/works、archive/archives、term/terms、procedure/procedures、event/events。
以身份而非字面名称判断重复。同一对象已有文件时更新它；不同对象同名才使用年份、作者或地点等有证据的消歧信息。已定 slug 不因补知日期或加入主题任意变动；必要改名须更新直接引用并留映射。
正文采用真实原文名及可靠中文表述，未知译名不伪造。现实对象可能承担多个研究角色，不因类型标签或来源不同复制条目。
来源、字段和正文分别见 citation.md、knowledge-unit-field-contract.md、body-template.md；结构字段见 hierarchy-field.md。
