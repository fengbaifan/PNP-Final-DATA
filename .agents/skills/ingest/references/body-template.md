# 知识元内容结构

REV-019、020 确定三部分：**元数据、内容、关系与证据**。元数据统一见 knowledge-unit-field-contract.md；同一知识元保留一个固定文件，内容只在正文维护，不再复制一份类型属性 YAML/JSON。元数据用 YAML frontmatter，正文用“## 内容”和“## 关系与证据”组织；已有 relations 保留兼容位置，逻辑上属于第三部分。

## 内容的共同骨架

1. **描述**：中文、英文两段或多段，说明对象是什么、边界及必要语境。
2. **结构化信息**：简单属性用“字段—内容—依据”表；亲缘、经历、作品、评价、文献及历史变化用适合的多行表或列表。不要把所有信息塞进一个描述段。
3. **具体论述**：保存原文中的活动、情境、条件、例外和作者论证；可按问题分节，不能因为结构化而丢掉叙述的意义。

适用但缺证或尚未查询的项目在第三部分的“待补与争议”汇总，后续交 enrich；不填造事实或重复一份缺口清单。

这些是内容内部的组织方式，不是新增顶层业务部分或独立文件。描述与属性可以相互解释，但同一完整清单只维护一处。

```markdown
## 内容

### 描述

**中文：** 有来源支持的对象定义与边界。

**English:** A semantically equivalent description of the object and its boundaries.

### 基本信息

| 字段 | 内容 | 依据 |
|---|---|---|
| 按类型选择的属性 | 具体值及必要限定 | 来源及精确位置 |

### 按需的经历、清单或沿革

按以下类型范围组织；仅生成实际需要的表，不复制全套空模板。

### 具体内容

原文记载、作者解释、外部补充分别说明出处与支持范围。

## 关系与证据

### 关系

指向已有 relations 记录；待证的关系说明对象、语义与所缺证据，不冒充正式关系。

### 证据与支持范围

内容表中的依据对应 sources 所登记来源，补充所支持的事实、关系及未覆盖范围，不整段复制书目信息。

### 待补与争议

适用的缺口及当前处理状态。
```

## 各类型需审视的内容范围

下列是内容覆盖范围，不是要求从空白预填事实。用户明确列出的适用项目，应有已知记录或清楚的待补说明；无信息时可合并列一条缺口，不制造几十行空值。

| 类型 | 基础属性 | 多项信息与历史记录 |
|---|---|---|
| person | 全名、原文名及英文名；出生/死亡日期与地点、职业/身份、国籍或有依据的历史政治归属 | 名称与头衔、亲缘、教育/师承/学术与职业履历、作品清单、评价者及评价、相关研究著作/论文 |
| work | 作品名及题名性质、创作者与归属、创作时间/地点、材质/媒介/技法、尺寸、作品描述/题材 | 赞助人、委托人及委托条件、创作阶段、版本/复制、所有权与流传、历史和现存放地、评价及研究文献 |
| place（building） | 建筑规范名、所在地、设计师、建造/改建年代、建筑性质及用途 | 历史名称、各时期所有权与管理/使用者、设计与施工参与者、营建改造、内部重要作品及研究文献 |
| place（其他地点） | 地名、原名/别名、地点性质、地理位置 | 历史名称、行政/政治归属的时期变化、本书相关活动及研究文献 |
| institution | 名称、机构/政治实体性质、成立/终止年代、所在地与职能 | 改名/继承、成员与负责人、组织变化、赞助/收藏/活动及研究文献 |
| archive | 题名及题名性质、文献类型、作者/发收者、成文时间/地点、语言 | 卷册/版本、出版或保管信息、索书号/按需 DOI/ISBN、内容摘要、涉及对象、刊录/转引关系及研究文献 |
| term | 中英文及原语名称、定义、适用范围 | 历史用法/语义差别、定义者及出处、具体实例、辨析及研究文献 |
| procedure | 名称、目的、适用条件与对象 | 操作步骤、参与角色、投入/产出、方法变化、来源实例及研究文献 |
| event | 名称、事件性质、日期范围、地点 | 参与者及角色、缘起、过程、结果、不同来源叙述及研究文献 |

建筑仍是 place 的 building 子类，不另造第九类；内部独立作品仍属 work。图录/论文等文献统一为 archive。

## 人物清单的具体表达

- **名称与头衔**：名称/称谓、语言、性质（全名、称号、昵称、别名、荣誉头衔、贵族头衔）、适用时间和依据。爵位、职务不混作本名；全名待核时保留有据的惯用名。
- **生平属性**：日期记录约年、范围、历法或争议，不将活动年误作出生年。“国籍”按历史语境核对，出生地、文化身份与现代国籍不同义，不以现代国界反推。
- **亲缘关系**：对象、亲缘类型、时间/限定、依据；师生、同事、赞助关系不放入亲缘。
- **学术/职业履历**：时间、机构或师承对象、学习/任职/活动内容、地点、依据。历史画家可有学徒、师承和行会/学院经历，不硬套现代学位；确属不适用时解释。
- **作品清单**：作品名/已有 KU、角色、时间、完成/存世或归属状态、依据。注明本来源涉及、已核实或待补范围，不能把几项样例叫全集；委托方案不等于已完成作品。
- **评价**：评价者、所评对象或方面、评价内容、原话/转述性质、发表时间与文献、定位。评价者的判断不是客观事实，不能只罗列评价者姓名。
- **研究著作/论文**：题名、作者、年份、出版/刊载信息、研究对象与相关性、已读/仅书目线索状态及来源。人物自己的著述与研究该人物的文献分开；已有 archive 则链接，不复制文献卡，不假称读过原件。

## 作品与建筑的时间变化

作品的创作时间、委托时间、完成时间分别记录；创作地点与现收藏/存放地点分别记录。作者归属和赞助角色按证据说明，不能由一个人付款推断其设计或创作。

建筑历史名称用“时期—名称—适用范围—依据”，所有权沿革用“时期—所有者—权利/取得或转移方式—依据”；管理者、占用者、赞助人另注明角色，不当作所有权。年代不明或阶段重叠如实记录，不填造连续时间线，不以当前名称或所有者覆盖历史。地点和沿革列表均应说明来源描述时间，未核现状不能写“现存放于”。

## 表达与证据

- 标题与描述中英文对应（REV-018），字段可用“中文 / English”标签，姓名/题名有可靠双语形式时并列。描述修改时同步事实、数值、否定与不确定性；自写英文不是来源引语。
- 每个属性或同源记录组绑定具体来源位置；来源内记载、作者解释、外部补充和自身推断分开，不用整卡的来源列表给全部字段背书。
- 缺口区分“尚未查证”“已查资料未载”“来源冲突/有争议”“不适用及理由”；空值或未收录不等于对象没有该项属性。没有外证的全名、生卒年等不从模型记忆填入。
- 亲缘、创作者、赞助、收藏、设计师等内容可先作为有据记录保存；形成正式图谱关系仍依 relation-types.md，须有有效端点、受控类型、方向和具体证据。正文链接/表格不自动成为正式边，不维护两套独立关系真值。
- 第三部分集中说明正式/待证关系、证据支持范围、未决项；正式关系的唯一机器记录仍为 KU relations，复杂断言引用 claim-registry 的对应记录，不复制一套。没有正式关系时如实说明，不凑边；证据可以支持原文记载而尚不支持独立史实确认。
- 不新增预设 Topic/Theme 或“层级位置”，不因内容模板开启后续发现与页面。现有 relations 与证据位置保持兼容，网页不在本次刷新范围。
