# 知识元内容结构

REV-019、020 确定三部分：**元数据、内容、关系与证据**；REV-041、042 将内容细化为分组字段和多条记录。本文件是九类实体正文结构的唯一模板；按本次对象类型读取相应小节，不要求遍历全部类型。

同一实体保留一个固定 Markdown 文件。共用元数据用 YAML frontmatter，字段含义见 knowledge-unit-field-contract.md；类型属性只在正文保存，不另复制属性 YAML/JSON。已有 relations 保留 frontmatter 兼容位置，逻辑上属于第三部分；正文须提供可阅读、可点击的关系展示，不能只让读者查文件头。模板更新不表示既有卡已迁移、重新补足或通过验收。

## 共同表达规则

- **独立字段**：一个字段表达一个属性。全名、惯用名、昵称、头衔分开；父亲、母亲分开；创作者、委托人、赞助人分开；出生地、去世地分开。不使用“姓名及亲缘”“生卒及国籍”等混合字段。
- **重复条目**：多名配偶、子女、多种身份、多次任职、多件作品、多个版本分别列条。同年发生不同活动也分条，不在一个单元格串成简历。以下模板表中分号隔开的名称表示独立字段，不是一个合并字段名。
- **可读结构**：单值信息用“字段｜值｜证据”表，每个字段一行；重复信息用小节下的列表或多行表，每条具有本节规定的要素。使用哪一种以清楚可读为准，不生成两份相同清单。
- **双语**：保留中文和英文描述；名称、题名及有据角色提供对应语言形式，原语名另列。无通行译名时注明暂译；翻译不补造事实。正文不要求重复两份完整语言表。
- **时间与数值**：日期可到年、月或日，保留约年、范围、历法和不确定性；只有年份时不补为 1 月 1 日。一个日期值可直接提供生年／卒年，不再手工维护重复年字段。尺寸明确量纲、单位及测量对象，金额明确币种与时期。
- **内容与依据分开**：字段值保存事实及必要限定，证据栏给来源编号和精确位置；完整来源只在 sources 登记。字段采用理由和冲突的详细分析放 03 过程；卡内第三部分保留当前裁决、备选值及对应依据。
- **保留语义**：字段之外保留“本章相关内容”，表达原文活动、条件、例外与作者论证。不能因拆字段丢失语境，也不以一般百科生平替代本章内容。
- **按需填写**：类型模板规定审视范围，不要求每卡都有所有字段、空表或预设数量。适用但未查／资料未载／有争议／不适用及理由集中记入第三部分。未载不等于不存在。

```markdown
### 身份与外部链接
| 字段 | 值／链接 | 状态与范围 |
|---|---|---|
| 类型适用的权威记录 | 数据库名、记录名、稳定标识及可点击链接；多库分条 | 说明用于身份、书目、档案层级、馆藏还是事实补证 |

| Wikipedia（如有） | 实际采用的条目名、语言及可点击链接 | 与QID的核对结论和全文阅读范围分别说明；无准确页面时可省略 |
| 数字化原件／全文（如有） | 保管或平台、item／馆藏标识、版本及可点击链接 | 区分目录页、OCR、扫描图和实际已读页 |

### 关系记录
列出本卡已有正式关系的简明展示：关系含义 → 关联知识元（名称链接到该 KU 的实际相对路径），注明必要语境及证据。多条时可用“关系｜关联知识元｜语境与证据”表；与元数据保持一致，不另设一份机器关系字段。没有正式关系时如实说明；有据内容关联和待证关系另作明确标识。

### 证据与支持范围
必要时解释证据对应的字段、记录或同源组，使用 sources 的来源编号和具体位置。

### 争议与待补
按字段或条目列当前采用值、其他来源值及其证据；未裁定则明写未裁定。
```

## 通用条目格式

各类型按需使用下列格式，类型小节只列专用字段。每条都有证据引用；时间或角色不明时保留未明，不自行补齐。

| 条目组 | 每条记录的要素 |
|---|---|
| 履历／沿革 | 时间或起止时间；活动类型；活动内容；关联人物／机构；地点；证据 |
| 历史名称 | 适用时间；名称；语言；适用范围；证据 |
| 参与者／成员 | 人物／机构／家族或已有实体引用；具体角色；适用时间；证据 |
| 所有权变迁 | 时间；所有者；权利范围；取得／转移方式；关联对象；证据 |
| 管理／使用／存放 | 时间；管理者／使用者／保管机构（按角色分条）；地点；对象范围；证据 |
| 作品清单 | 作品名称或已有实体引用；本实体的角色；时间；完成／存世／归属状态；证据 |
| 评价 | 评价者；时间；所评方面；评价内容；原话或转述；出处与定位 |
| 研究文献 | 文献题名或已有 archive 引用；作者／编者责任；年份；出版信息；相关性；已读／仅书目线索；证据 |

履历按时间先后组织；单次事件、时间区间、持续任职分别表达。地点变动记录起点和终点，任职记录机构和职位，购置记录对象和权利，不仅保留一个年份。教育与职业履历分组时，同一学习条目只维护一次。其他类型同理：总年表引用专门沿革记录，不重复维护完整事实。

## 人物 person

| 分组 | 独立字段／条目 |
|---|---|
| 姓名 | 全名；惯用名；别名；昵称；原语拼写。人物规范展示名以有据全名为主，不变更稳定路径 |
| 称号与头衔 | 荣誉称号、贵族头衔、其他称谓分别成条：名称；性质；授予者；授予／适用时间；证据 |
| 基本信息 | 性别；出生日期；死亡日期；出生地；去世地；国籍或历史政治归属；文化归属 |
| 身份 | 画家、素描家、赞助人等分别成条：身份标签；必要的活动时期／语境；证据。示例不是每人必有的身份 |
| 亲缘 | 父亲；母亲；配偶；女儿；儿子；姐妹；兄弟；其他亲属。各关系分别记录对象、关系性质、必要时间及证据；配偶、子女等允许多条 |
| 家族归属 | 家族；支系；归属方式；时间；证据 |
| 教育与师承 | 时间；教师或机构；学习内容；地点；证据 |
| 职业与生平履历 | 依通用履历格式逐条记录工作、迁居、任职、委托、购置等活动 |
| 作品 | 依作品清单格式；本人著述／书信另列 archive 引用，不混入研究该人物的文献 |
| 评价与研究 | 分别依通用评价、研究文献格式记录 |

父母存在生物亲缘、收养或继亲等不同性质时分别说明，不能强制压成唯一无条件父／母。称谓不能推定性别或亲缘；师承、同事、赞助不放入亲缘。历史画家不硬套现代学位。Principe 等机构职务记录在任职条目，不自动当贵族头衔；国籍、文化归属与出生地不是同一属性，多值按时期及来源保留。

| 规则与例外 | 规则或条件；适用情境；允许的变体／例外；证据 |
| 历史变化 | 时间；改变的环节／规则；地域或制度语境；证据 |
| 实施案例 | 时间；实际参与者；地点；作品／文献引用；实施过程；实际结果；证据 |
| 评价与研究 | 依通用格式 |

程序表达一般做法，事件表达一次具体发生。顺序或固定规则只有在材料支持时才列，不将一次个案推广为所有画家的惯例；预期输出与实际结果分开。

## 事件 event

| 分组 | 独立字段／条目 |
|---|---|
| 名称 | 中文名称；英文名称；原称／别称；题名性质 |
| 基本信息 | 事件性质；开始时间；结束时间；地点；事件描述 |
| 参与者 | 人物／机构／家族；具体角色；参与阶段；证据 |
| 背景与缘起 | 条件；相关先行事件；来源归因。事实背景和因果解释分开 |
| 经过 | 时间；阶段；行动者；行动；地点；直接结果；证据，每项行动成条 |
| 结果与后续 | 实际结果；发生时间；涉及对象；来源解释的后续影响及其判断主体 |
| 相关对象 | 作品；文献；地点；程序等已有实体引用及其与事件的具体联系 |
| 不同叙述与研究 | 各来源叙述的主体和范围；差异交第三部分，研究文献依通用格式 |

计划举行、尝试执行、实际发生与取消分别记录；并列发生不证明因果，后人的影响解释不等于当时结果。

## 关系、证据与过程的分工

- sources 保留统一来源登记。正文默认 S1、S2 等指向既有来源顺序，加具体章页、行段或网页小节；引用可直接用清晰书目短称。新增来源追加，重排或合并时同步所有引用，不另外强建一套证据编号系统。
- 同一来源只有精确段落确实同时支持一组字段时才能共用引用；不能用整卡来源列表为全部属性背书。外部来源与本书记载分开，模型解释不冒充独立来源。
- 第三部分按字段／条目记录争议：各值及其来源；当前采用值或未裁定；简短理由。完整裁决过程、访问失败、采集修订号／指纹、WD rank 和原始限定词等留在 03 必要证据；影响事实含义的时间、角色、精度必须保留在内容中，不能因排版清理而删掉。
- **身份入口**：在第三部分集中展示与类型相符的权威记录、稳定标识和链接，如人物辞典／规范号、档号／索书号、书目号、馆藏号、数字化item、QID或Wikipedia页面。只列实际核对且同粒度的入口，不使用相关人物、作者或机构的标识代替本对象；没有QID或百科页不列为缺陷。核对依据、访问版本和数据库能力留在既有过程证据，卡内说明各入口支持身份、版本、馆藏、书目还是正文；链接存在、身份通过、全文已读和内容补足完成分别表达，不增加重复frontmatter身份字段。
- **关系展示**：正式关系依 relation-types.md，用已有 relations／claim bindings 保存唯一机器记录。第三部分直接展示本卡已有关系的含义、方向、关联知识元链接及必要语境／证据，可用短句或简表；这是同一记录的阅读展示，不另建关系文件或第二套字段。编辑正式记录时同步受影响展示，不让用户只能读原始路径或“见元数据”。反向关系不手工复制为新的事实。
- **内容关联**：亲缘、创作者、赞助、收藏、设计师等字段中，身份已能对应到已有 KU 时直接链接其固定路径；未有 KU 或同一性未定时保留有据姓名与说明，不造路径、不为补链接新建实体。关系词表缺项不妨碍展示带证据的内容关联，但这种链接不自动成为正式边；发现内容和正式边矛盾时核对具体事实，不强行统一状态。
- 复杂断言引用 claim-registry 的对应记录，不能以断言自身为证据；评价保留评价者和出处。不为达到字段覆盖、关系数量或健康分数增加审核、事实或对象。
- 既有卡在实际成稿／补足整理时逐张采用新结构，保留原文信息、来源定位、有效关系及历史裁决。改格式不等于新补足、重新验证或增加覆盖数；过程指向原卡及固定证据路径，不另建“新版”卡或迁移状态总账。
- 已有补足记录若保存了 applied_content_sha256，之后改写卡片时在同一过程证据文件追加当前应用记录，关联前后版本；旧指纹只证明当时内容，不回填或覆盖为当前值。当前一致性检查取该卡最新已应用记录，采集记录不冒充已应用结果；没有使用此类记录的普通编辑不为此新建机器台账。
- 不新增预设 Topic/Theme 或层级位置，不因模板升级启动后续发现及页面；元数据、验证写回接口和关系兼容位置保持原约定。
