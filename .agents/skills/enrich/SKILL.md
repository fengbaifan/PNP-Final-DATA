# enrich

负责阶段 5，围绕可用知识元的明确缺口补足。

## 输入与工作

读 KU、对齐结果与本次缺口，判断缺少的是定义、身份边界、语境、事实还是出处。以来源内容为核心，按 REV-056 从原始材料、保管或责任机构、专业数据库、规范库、书目／手稿目录、数字化全文、研究文献和适用百科中选择能回答该缺口的来源，不要求每个实体遍历固定网站清单。
来源选择按对象类型执行：人物可用国家人物辞典、SIUSA等档案生产者记录、Getty ULAN、VIAF／国家规范库和所属机构资料；意大利人物按需使用Treccani《意大利人传记辞典》。文献与档案优先保管机构、档号／索书号、OPAC SBN、EDIT16、Manus Online和可核版本的Internet Archive等数字化全文；作品、地点、机构、术语等使用相应馆藏、文化遗产目录、Getty词表和官方记录。具体来源与限制见verify的按类型参考。
Wikipedia与Wikidata只在存在同粒度准确对象时使用并遵循verify；Wikipedia页面或QID缺失不阻止利用其他权威来源完成身份和内容补足。确认QID后可提取适用结构化属性，同时读取限定词、时间精度、单位、rank与引用；多值及冲突保留，缺字段不造值，候选实体未确认前不批量导入字段。被引用实体标签需实际核对；任何外部标识都不自动接收新KU或建立正式关系。已经语义采纳、可独立识别并承担人物作品清单、师承、亲缘、委托、创作、安置、存放等必需字段或关系端点的对象须显式交回 ingest 建立或复用 KU；身份、版本或来源尚不足时保存为待决端点，不能只留一个无法连接的名称。
采用Wikipedia时应完整阅读正文、信息框、相关表格、图注及页面注释／书目；采用人物辞典、馆藏、档案或数字化文献时同样记录实际条目／版本、可得标识、阅读范围与采纳／暂缓理由。数字库的目录页、OCR、扫描图和原件正文分别标明；书目命中不等于读过原件，全文平台可访问也不等于已阅读。字段资料、叙述解释及补证按事实绑定来源，不机械拼接数据库内容。
阅读外部实际正文/记录，只补与理解本书对象及关系有关的内容，不堆积链接、扩写完整百科或填满模板；记录采用内容、准确出处和实际访问日期。书目记录只能支持书目事实，不等于读过被引文献原件。
采用内容准确表述，区分原文、外部补充和自身解释；标题与描述按 ingest 字段及正文规则保持中英文对应，修改一侧时同步另一侧，不扩大事实或验证范围。同一条证据判断不重复审核。新来源/新对象若只是网页外链或背景线索则不自动扩张任务；若它已被本次内容采纳并承担必需字段或正式关系端点，则在当前受影响范围内回 ingest，随后只重走该对象的对齐、补足和关系，不递归采集其全部外链。
原文关系候选用于确定补足问题，不是外部采集结论。外部来源发现或支持关系时，另记事实、证据和候选锚点；同一关系的书内与外部证据可以并列，但各自支持范围分别保留。外部材料不得覆盖原文中的否定、推测、转述、时间或版本限定，也不得将现藏事实改写为原定安置。

## 产出、状态与交接

过程在 03-processing/<task-id>/process/knowledge.md，结果在 04-knowledge/results/<task-id>.md，正文原位更新。记录补了什么、来源、未解决项及阻断性。
按 ingest 正文参考的对应类型逐组补足：单值独立字段、多值分条、履历／沿革按时间逐项，并保留本章语境。历史名称、所有权、收藏位置不以当前值覆盖旧值；字段保留事实及证据引用，争议放第三部分，采集与裁决过程放 03。实际整理的旧卡原位采用新结构并核对信息保留，不以模板更新或格式调整增加补足覆盖数。不能仅因摘要可读就判断无须补足；核实信息才能写入，未查、资料未载、争议与不适用分开。
身份配对已完成且无实际内容缺口时，可记已审查无新增；查过但未找到证据记问题未解决，不能记补足完成。双重验证未完成的对象保留原文支持状态及其有证据的关系，不把这一缺口变成删除依据；身份冲突或关键关系依据仍缺失时阻断对应合并/关系，其他可用内容带限制交 relate。
新增证据影响身份/验证判断时回 verify，涉及机器状态写回才调用其受控接口。知识增长不自动触发 synthesize。
