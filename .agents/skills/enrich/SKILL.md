# enrich

负责第五阶段，围绕已对齐知识元的明确内容缺口补足。目录分类不代表自动启动知识发现。

## 输入与执行

1. 阅读条目和对齐结果，列出影响对象理解的缺口：定义、边界、历史语境、必要事实或出处。
2. 先用已有来源；确需外部资料时，读取能直接支持目标问题的正文及必要引文。搜索摘要、QID 和链接不是补足结果。
3. 以中文语义重述补写，明确原书内容、外部补充与自身判断；不机械扩写传记、堆砌链接或强制新增字段。
4. 使用网页书目时仅保留与当前缺口直接有关的来源。新增对象/主题线索只记待处理，不自动扩张知识元或启动 synthesize。
5. 补证涉及验证状态时使用 verify 的 evidence→dry-run→apply 接口；补写不得伪造验证等级。

## 输出与完成

过程：04-knowledge/process/<id>.md，记录缺口、实际阅读来源、采用或否决理由。
结果：04-knowledge/results/<id>.md，记录补了什么、依据、剩余缺口；正文在 units 原文件版本更迭。
完成指本次明确缺口得到支持或说明证据不足，不要求条目达到任意篇幅。无需补足时记录已审查无新增。具备条件后交给 relate。
