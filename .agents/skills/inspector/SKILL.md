# inspector

按指定问题审查内容、来源、证据或系统，不构成额外生产阶段。

读对象、相关过程/结果及适用规则，指出具体问题、证据、影响对象和是否阻断，交回责任阶段。语义质量靠实质阅读，数量、文件存在或结构分数不能代替判断；自查不称独立正式验收。
只检查受影响范围，已通过且无新证据的判断不重复审核。编码疑点先核对原始字节和解码，不能仅因终端显示修改来源。
业务审查记录回对应过程/结果；系统审查记既有 CHANGELOG.md。不另产一套与阶段结果重复的报告。
必要时使用对应 audit/校验工具；不默认运行全库脚本。规则修订交 system-upgrade，事实或关系问题回各自阶段，未开展的层级不列为必须修补项。
