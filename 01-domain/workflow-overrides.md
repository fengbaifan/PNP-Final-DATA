# 本项目的材料与语言约定

通用流程见 AGENTS.md 和 pipeline，本文件只补充本项目约定。

- 初始来源为用户指定的《赞助人与画家》材料，版本与具体范围每次摄入明确。来源事实、作者论述、外部补充和 Agent 解释分别表述。
- 沟通和研究记录以中文为主；知识元标题与描述中英文对应，正文采用统一元数据、类型内容、关系与证据三部分，按 ingest 的字段/正文规则执行。人名、书名、机构、作品与术语保留必要原文，引用保持来源原语言；暂译和未核名称明示，不编造官方译名。
- 8 类 KU 作为初始表达词表，不要求凑齐类型实例；若确有无法表达的对象，先记录问题并作语义判断，不机械套类。
- 具体 Topic、Theme、Dimension、Domain 均由第二部分自下而上的分析形成。没有预设归属，不以缺少层级记研究债务。
- 来源、旧试填及历史报告不自动成为本项目正式成果。accepted.yml 只登记实际写入且已完成对应阶段判断的对象；KU 成稿接收不代表事实已外部核实，结构接收需涌现依据。
- 新对象可以引用已有对象；不为新来源或新类型标签复制同一现实对象。
