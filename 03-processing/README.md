# 来源与知识处理过程

按 [pipeline](../.agents/pipeline.md) 的 S0–S7 顺序执行。当前全书 S2 已完成内部处理并具备交接条件，状态及限制见[全书结果](../04-knowledge/results/patrons-and-painters-full-book-s2.md)。每个实际任务使用稳定目录：

- process/stages.md 保存摄入、处理的必要裁决；阶段收口后，完整逐行分析、来源范围、章页与句意摘要、校正、覆盖依据及交接缺口统一保存于 results/stages.md 定稿，过程不复制一份。
- process/knowledge.md 按 S3 身份对齐、S4 KU 登记、S5 补足、S6 关系（及后续明确启动的发现/涌现）分节保存范围、实际依据、语义判断、取舍和修改理由；当前知识成果及结果说明位于 04-knowledge/results/<task-id>.md 和其引用的唯一成果。

过程文档在同一任务包原位更迭，不另建 04-knowledge/process 或按轮次复制。来源登记留在 02-sources；呈现过程仍在 05-outputs，系统治理记录仍在 06-runtime。

没有任务时不创建空包。正常语义工作保留可定位的覆盖与候选依据即可，不强制输出 JSONL 五件套。按 pipeline 在每阶段定稿后清理重复过程与已被替代的中间产物；必要证据保留，旧包退役前核对历史可恢复性及派生依赖，不把旧 completed 当本项目已执行。

任务包 process 内的具名处理脚本是针对当时输入的操作与恢复记录，不是另一套日常执行顺序；复验前须核对其输入、预检和适用范围，不能按目录顺序重放或对当前事实表批量重跑。临时截图、备份和 `.tmp` 文件不作为正式成果入口。
